A clean, **ATS-friendly** LaTeX resume template designed specifically for **software engineers and developers**. This template balances modern aesthetics with professional simplicity, ensuring your resume stands out to both human recruiters and automated tracking systems.

## ✨ Features

- **ATS-Optimized Layout** - Clean single-column design that parsers can easily read
- **Modern Typography** - Professional fonts and spacing for excellent readability
- **Customizable Sections** - Easy to add/remove skills, experience, projects, and publications
- **Open Source Contributions Section** - Highlight your GitHub, Stack Overflow, and community work
- **Contact Icons** - Built-in FontAwesome5 support for LinkedIn, GitHub, Email, and more
- **Clean Code Structure** - Well-commented LaTeX that's easy to modify
- **PDF & Print Ready** - Optimized for both digital viewing and printing

## 🎯 Perfect For

- Software Engineers & Developers
- Front-End Specialists
- Open Source Contributors
- Computer Science Students
- Tech Professionals with GitHub presence
